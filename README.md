# DB Autodetailing — zelenošedý redesign s galerií

Pět HTML podstránek, responzivní CSS, mobilní menu a galerie s lightboxem na Úvodu a ve Službách. Galerie má šest vlastních SVG ilustrací, které jsou **zástupné**: nejde o fotografie skutečných realizací DB Autodetailing.

Pro nahrazení fotografiemi se souhlasem vlastníka vložte obrázky do `galerie/` a upravte cesty a popisky u galerie v `index.html` a `sluzby.html`.

Web je neoficiální návrh, nikoliv web provozovaný firmou. Formuláře nejsou připojené k backendu.

Pro GitHub Pages nahraj všechny soubory včetně celé složky `galerie` do kořene repozitáře.


## Fotografie a mapy
Fotografie byly dodány uživatelem a jsou vložené v `fotografie/`. Před veřejným použitím je potřeba potvrdit oprávnění k jejich zveřejnění s držitelem práv.

Google Mapy na stránce Kontakt používají vyhledávací dotaz „DB Autodetailing David Baják Klimkovice“, nikoliv ověřené GPS souřadnice. Před předáním klientovi ověřte přesnou adresu a podle ní nastavte mapový odkaz a iframe.

Úvod obsahuje rychlou navigaci na sekce, fotografie realizací a jediné tlačítko pro všechny služby.
